# Zoryn Engine Cycle

## Philosophy

Zoryn never "runs a model."

It continuously evolves its understanding of the Earth.

The engine is therefore a perpetual knowledge evolution cycle.

---

# The Cycle

```
            New Observations
                    │
                    ▼
          Validate & Standardize
                    │
                    ▼
           Resolve Entities
                    │
                    ▼
            Create Observations
                    │
                    ▼
              Update States
                    │
                    ▼
          Update Graph Structure
                    │
                    ▼
          Update Learned Memory
                    │
                    ▼
        Detect Emerging Patterns
                    │
                    ▼
         Forecast Graph Evolution
                    │
                    ▼
          Explain Predictions
                    │
                    ▼
          Publish New Knowledge
                    │
                    └──────────────┐
                                   │
                                   ▼
                         Wait for New Data
```

---

# Stage 1 — Observation

Receive new information.

Nothing is interpreted.

---

# Stage 2 — Validation

Reject impossible observations.

Standardize units.

Assess quality.

---

# Stage 3 — Entity Resolution

Determine which graph entities are affected.

Examples

- H3 cells
- Rivers
- Lakes
- Roads

---

# Stage 4 — State Evolution

Produce new immutable states.

Never overwrite history.

---

# Stage 5 — Graph Evolution

Update relationships.

Strengthen or weaken learned connections.

Discover new relationships.

---

# Stage 6 — Memory Evolution

Compress knowledge.

Store significant transitions.

Forget redundant information.

Never forget rare events.

---

# Stage 7 — Pattern Discovery

Search for:

- recurring trajectories
- emerging trajectories
- anomalous trajectories

Hazard labels are optional.

---

# Stage 8 — Forecasting

Forecast future graph evolution.

Not variables.

Not hazards.

Graph evolution itself.

---

# Stage 9 — Explanation

Every forecast records:

- supporting evidence
- confidence
- similar historical episodes
- uncertainty

---

# Stage 10 — Publication

Expose knowledge through:

- API
- CLI
- Dashboard
- Streaming events

---

# Design Rules

1. The graph is the only source of truth.
2. Every cycle is append-only.
3. Learning is continual.
4. Every stage is independently replaceable.
5. The engine never stops learning.
