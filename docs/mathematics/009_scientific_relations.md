# Scientific Relations

## Purpose

This document defines the mathematical relationships that exist within the Dynamic Process Network.

Relations describe how scientific objects are connected.

Operators act upon relations.

---

# Definitions

## Definition 1 — Scientific Relation

A scientific relation is a formally defined association between two or more scientific objects.

Relations possess meaning.

Relations may evolve through evidence.

---

## Definition 2 — Binary Relation

Let

A

and

B

be sets.

A binary relation

R

is

R ⊆ A × B

Every scientific relation is represented mathematically as a subset of a Cartesian product.
