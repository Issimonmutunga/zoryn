# Scope

This document describes the hydrological principles used to identify
developing flood conditions.

Unlike meteorological hazards, floods result from the interaction of
multiple environmental processes rather than rainfall alone.

# Core Principle

Floods occur when water input exceeds the capacity of the landscape and
drainage system to store, infiltrate, or convey water.

Rainfall alone is therefore not sufficient evidence of flooding.

---

# Primary Drivers

Examples include

- rainfall intensity
- rainfall duration
- accumulated rainfall
- antecedent rainfall
- soil saturation
- watershed characteristics
- terrain
- drainage network
- land cover

---

# Flood Development

Flood conditions generally evolve through stages.

```
Dry Conditions

↓

Rainfall

↓

Soil Moisture Increase

↓

Antecedent Wetness

↓

Runoff Generation

↓

River Response

↓

Flood
```

# Planned Warning Logic

Flood warnings should be generated using multiple supporting indicators.

Examples

Persistent rainfall

+

High antecedent wetness

+

Steep terrain

↓

Elevated flood hazard

---

# Design Principles

Flood reasoning should

- integrate multiple variables
- recognise temporal persistence
- distinguish rainfall from flooding
- remain scientifically explainable

---

# Limitations

Flood behaviour depends on

- watershed size
- soils
- vegetation
- infrastructure
- local hydrology

No single environmental variable should be interpreted as proof of flooding.
